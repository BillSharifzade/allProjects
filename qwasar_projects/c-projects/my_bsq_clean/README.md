# Welcome to My Bsq
***

## Task
The problem is to find the biggest square in a map filled with obstacles.

## Description
The solution reads a map file, analyzes it, and finds the largest empty square.

## Installation
To install the project simply run `make` command in the project directory.

## Usage
To run the program use `./my_bsq map.txt` where map.txt is your input file.
